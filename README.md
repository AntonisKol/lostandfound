# Fundstück - Lost & Found App

**Work in Progress 🚧**

Fundstück is a mobile app for reporting and finding lost and found items. Users can post items they’ve found, mark items they’ve lost, and browse items in their area. The app includes a feed, map view, and item details.

## Features

- Post found items with image, category, location, and notes
- Browse found items in a feed
- View items on a map
- Mark items as returned/found (planned)
- Post lost items (planned)
- User accounts with email, password, and zip code (planned)
- Chat feature (planned)
- Notifications for items in your area (planned)
